## 규칙

1. 기능을 만들거나 고치면 해당 항목의 판정과 근거 파일을 같은 변경에서 고칩니다.
2. `대상 아님`은 문서가 명시적으로 미룬 항목이나 사용자가 미루기로 정한 항목만 씁니다. 근거 행을 적습니다.
3. 명세보다 단순하게 만들 때는 먼저 사용자에게 묻습니다. 묻지 않은 단순화는 `부분`이고, 완료가 아닙니다.
4. 진행 보고는 시험 개수가 아니라 이 표의 숫자로 합니다.
5. 화면 항목은 실제 화면을 목업과 나란히 놓고 확인한 뒤 구현됨으로 바꿉니다.

판정 시각: 2026-11-02 21시 작업본. 코드 대조는 정적 읽기로 했고, 화면 항목의 규칙 5 목업 대조는 아직 하지 않았습니다.
