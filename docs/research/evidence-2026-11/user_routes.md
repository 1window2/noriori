# 사용자 경로 (자료별)

자동 요청으로는 닿지 않아 사람이 직접 열람하거나 신청해야 하는 자료를 열람처별로 묶었습니다. 각 자료마다 접근 조건, 신청 방법, 그 자료로 풀 수 있는 항목 id를 적습니다. 조사 중에 계정을 만들거나 로그인하지 않았습니다. 항목의 판정·근거·시도한 경로는 같은 id로 `stations.tsv` 등 근거 표에서 찾습니다.

열람처 설명은 원래 기록(`user_routes.json`, `names_dates.json`, `km.json`, `inventory.json`, `results.json`)의 글을 그대로 옮겼습니다. 묶음 제목과 순서만 압축하면서 붙였습니다. 2026-11-12 스냅숏입니다.

- **접근 조건**: NDL 이용자 본등록. 원래 기록의 설명:

  - 『名古屋鉄道百年史』(1994)·『名古屋鉄道社史』(1961)·『写真でつづる富山地方鉄道50年の歩み』(1979)도 Lab(공개본) 검색에 안 걸림 → 인터넷 공개 아님. 送信 대상 여부는 위와 같은 이유로 직접 확인 못 함(사용자 확인 필요). 1952년 뒤 官報: 送信サービス 대상(사용자가 등록하면 볼 수 있음)
- **신청 방법**: NDL 디지털 컬렉션에서 서명 검색 → 「個人向けデジタル化資料送信サービス」 표시 확인 → 본등록 뒤 열람. 遠隔複写(우편 수령)는 본등록 뒤 복사 신청.
