# 근거 목록 보존 (2026-11)

2026-11-05부터 11-12까지 진행한 조사(3차 조사, 1·2회차 전수 대조, 감사 분류, 근거 탐색)에서 **출처, 판정, 시도한 경로, 사용자 경로**를 저장소에 남깁니다. 장기 유지보수, 수록 범위를 넓히거나 줄일 때, 아카이브에 씁니다.

- **스냅숏**: 2026-11-12 기준입니다. 근거 탐색은 그 뒤에도 이어졌으므로, 판정이 다르면 「외장 아카이브 noriori-evidence」의 원본이 최신입니다.
- **원본**: 조사 원자료 전체는 외장 아카이브 noriori-evidence에 있습니다. 표에 나오는 `r3/…`, `r4_evidence/…`, `audit2/…` 같은 경로는 그 안의 위치입니다.
- **압축 원칙**: 저장소에는 원본 JSON을 읽기 좋은 표로 옮긴 압축본만 둡니다. JSON 껍데기와 중복(같은 항목의 같은 칸에 같은 글이 되풀이된 것)만 걷어 냈습니다. URL, pid와 쪽, oldid·rev, 날짜, 값은 바꾸지 않았습니다. 탭과 줄바꿈만 공백으로 바꿨습니다.

## 장기 유지보수에서 이 폴더의 자리

`data/overrides`의 손 보정 행은 행마다 근거 칸을 가집니다. 그 근거 칸이 **1차 기록**입니다. 앞으로 audit 검사가 근거 칸이 빈 보정 행을 오류로 잡아 이를 강제합니다. 이 폴더는 그 근거를 찾은 **과정의 기록**입니다. 행의 근거 칸과 이 폴더가 다르면 행의 근거 칸을 따릅니다. 보정 행에 근거를 옮길 때 이 표의 id·URL·인용을 씁니다.

## 판정 기준

조사 공통 규칙(`r3/COMMON.md`, `r4_evidence/SLICE_COMMON.md`)을 따릅니다.

- **신뢰도**
  - 높음: 공문서(官報, 簿冊), 정부 통계와 조사표, 사업자 공식 자료(社史, 발표), 당시 시각표
  - 중간: NDL 스니펫, 출전이 명시된 위키백과나 문헌
  - 낮음: 출전 없는 자료
- **가용**: 높음 하나, 또는 서로 독립인 중간 둘 이상이 일치할 때입니다. 「가용(후보 기각)」은 근거로 후보를 버린 것, 「가용(축 결정 필요)」은 값은 섰고 km 축 선택만 남은 것입니다.
- **유실 확인**: 남아 있지 않다는 근거가 있거나, 일반인이 쓸 수 있는 경로를 모두 써 본 기록이 있을 때입니다.
- **사용자 경로**: 등록이나 직접 신청이 있어야 볼 수 있는 자료입니다. 접근 조건만 적었습니다. 조사 중에 계정을 만들거나 로그인하지 않았습니다.
- **진행 중**: 근거를 아직 찾는 중입니다. **반영됨**: 이미 DB에 들어갔습니다. **제외(대조 오류)**: 대조 자체가 잘못된 짝이었습니다.

## `r3_sources_1.tsv`, `r3_sources_2.tsv`

3차 조사(`r3/*/result*.json`, 주제 44개) 결과에서 **결론의 출처만** 항목별로 짧게 남겼습니다. 3차 조사의 결론은 대부분 이미 DB와 보정 파일에 들어갔고, 보정 행 근거 칸으로 옮기기 전까지는 이 표가 저장소 안의 출처 기록입니다.

| 칸 | 내용 |
|---|---|
| 주제 | `주제 폴더/결과 파일` |
| 항목 | 결과 파일 안의 위치(`rows[3]`, `stations_126[16]`, `노드|이름` 등) |
| 이름표 | 그 항목의 id·이름·노선·사업자 |
| 판정 | 짧은 판정 값(verdict, should_add, confidence, period, kana 등 200자 이하). 긴 설명은 원본에 있습니다 |
| 근거 | `URL 「인용」 키=값 …`, 여러 개는 ` ; `. URL 칸이 없는 근거는 `source=` 글(위키 판 번호 등)로 적습니다 |

걷어 낸 것:

- 위 항목별 근거 표에 같은 URL과 같은 인용이 이미 있는 근거.
- N05(국토수치정보) 점 기록을 옮겨 적기만 한 근거(「N05-24 Station2 …」). 저장소의 N05 원자료에서 그대로 다시 얻을 수 있습니다.
- 검색·수집 과정 기록. `coverage_gov`의 searched(국립공문서관 簿冊 검색 범위)와 licensed_entities(면허 사업자 536곳 대조 목록, 簿冊 URL 약 1,100개), `freight5`의 keyword_files·unreadable_documents·documents_scanned_by_path_year(JR東日本 보도자료 Wayback 전수 조사의 문서 목록). 결론(missing_should_add, never_opened, boundary, jr_hits 등)과 그 출처는 표에 있습니다.

## 개인정보

- 로컬 경로와 임시 경로는 원본 스냅숏 때 이미 `(로컬 경로 생략)`, `(임시 경로 생략)`이나 위의 원본 안 위치로 바꿨습니다.
- 이메일, 기기 ID, 사람 이름은 넣지 않습니다. 문헌 저자 표기는 `저자 생략`으로 바꿨습니다. 개인 블로그와 SNS 주소는 `(개인 블로그·SNS 주소 생략, 호스트)`로 적습니다. 원래 표기가 필요하면 원본을 봅니다.
- 좌표 배열(`coords`)처럼 데이터 파일에 이미 있는 큰 값은 넣지 않았습니다.
